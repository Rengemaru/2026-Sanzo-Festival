# こどもバイブコーディング体験(大学祭)ルール

## この体験について
- 体験者は幼稚園児〜小学生とその家族。1人あたり約8分。
- 子どもが言ったことを大人(スタッフまたは保護者)が入力する。
- 目的は「自分が言ったことが画面で動いた!」という喜びを体験してもらうこと。
- 正確さより、速さと「目で見てわかる変化」を優先する。

## ゲームについて
- このフォルダのゲームは「ざこ敵とボス」のゆるいシューティング。ゲームの種類(`MODE`)は変えない。
- 編集するのは `index.html` 1ファイルだけ(HTML/CSS/JavaScriptがすべてこの中にある)。
- 操作はキーボードのやじるしキー(↑ ↓ ← →)だけ。自分のキャラは画面の上から35%より下を自由に動ける。弾は自動で出る。
- 弾は、ふしぎな光の玉。やさしい黄色にふわっと光る、かわいくて不思議な見た目にする(暗い・不気味な見た目にはしない)。
- シャボン玉に当たると、自分のキャラが一瞬(0.6秒)目を回して動けなくなる。そのあと1.5秒は少し透けて、シャボン玉に当たらない。
- ゲームオーバーはない。
- ざこ敵
  - 上からゆっくり降りてきて、シャボン玉を ぐるぐる(うずまき)に出す。自分のキャラのすぐ上まで来ると、シャボン玉は出さない。
  - 光の玉が当たると、目を回して頭の上で星がくるくる回り、ころんと倒れる。
  - 少しすると起き上がり、横に 👋 を出してゆらゆら手を振りながら、画面の外へ帰っていく(その場で消えない)。
  - 自分のキャラにぶつかっても、ぽよんと跳ねるだけ。
- ボス
  - 「ぐるぐる」(目を回させた数)が `bossAt` ふえるたびに、ボスが1体だけ上からおりてくる。ボスのあいだ、ざこ敵は出てこない。
  - B キーはスタッフ用(すぐにボスを呼ぶ)。消さない。
  - ボスは左右にゆれながら、`bossPatterns` の出し方を上から順番に切りかえてシャボン玉を出す。
  - 光の玉を当てると「ぐるぐるゲージ」がたまり、いっぱいになると目を回して倒れる。画面のシャボン玉はぜんぶはじける。
  - そのあと起き上がって手を振って帰っていく(その場で消えない)。
- 見た目と動きの設定は、ファイル冒頭の `CONFIG` にまとまっている。このファイルにない項目は、このゲームでは使わないので足さない。
  - `player`: 自分のキャラ(絵文字) / `playerSpeed`: 速さ / `playerSize`: 大きさ
  - `shot`: 弾。初期値は `"glow"`(canvasで描く、ふわっと光るふしぎな光の玉)。絵文字を入れると、その絵文字が弾になる
  - `shotColor`: 光の玉の色(`"glow"` のときだけ使う。初期値は黄色 `#ffd93b`。`"rainbow"` で虹色に変化)
  - `shotInterval`: 弾が出る間隔
  - `dizzyMark`: 目を回したとき頭の上で回るもの(絵文字。初期値は ⭐)
  - `enemyShot`: シャボン玉の見た目。初期値は `"bubble"`(canvasで描くシャボン玉)。絵文字を入れると、その絵文字になる
  - `background`: 背景の色(CSSの色指定。グラデーションも可)
  - `sounds`: 効果音のオン/オフ
  - `enemy`: ざこ敵のキャラ(絵文字) / `enemySpeed`: 降りてくる速さ / `enemySize`: 大きさ
  - `maxEnemies`: 画面にいるざこ敵の最大数(初期値 10、上限 20)
  - `enemyShots`: ざこ敵がシャボン玉を出すか(true / false)
  - `enemyShotPattern`: 出し方。`"ぐるぐる"` / `"はなび"` / `"まっすぐ"` のどれか
  - `enemyShotInterval` / `enemyShotSpeed` / `enemyShotSize`: シャボン玉の間隔・速さ・大きさ
  - `bossAt`: ボスが出てくる「ぐるぐる」の数
  - `boss`: ボスのキャラ(絵文字) / `bossSize`: ボスの大きさ
  - `bossHits`: ボスが目を回すまでに当てる回数(5〜60)
  - `bossPatterns`: ボスのシャボン玉の出し方のリスト。1つずつ `name`(画面に出る名前)、`pattern`、`speed`、`size`、`interval`、`time`(続く時間)を持つ。
    「ボスのシャボン玉を〇〇にして」と言われたら、ここを変えるか、1つ足す

## 変更のしかた(最重要)
1. 聞き返さない。曖昧な指示(「かっこよく」「ねこ」「すごいの」など)は、楽しい方向に大胆に解釈してすぐ反映する。
2. まず `CONFIG` の書き換えだけで実現できないか考える。
3. `CONFIG` で足りないときだけ、ゲーム本体に最小限の追加をする(例:背景に星を流す、当たったら画面が光る)。
4. 前の変更を消さずに積み重ねる。子どもが作ってきたものを壊さない。
5. 1回の変更ごとに、画面で必ず目に見える変化を起こす。
6. 変更は小さく速く。大きな作り直しはしない。
7. 「てき」と言われたら、ふつうは ざこ敵のこと。「ボス」「クジラ」「おおきいの」と言われたら、ボスのこと。

## 変えてはいけないこと
- ゲームの種類(`MODE`)は変えない。
- 操作方法(やじるしキーと自動発射)と、自分のキャラが動ける範囲(`PLAYER_TOP_RATIO`)は変えない。
- ゲームオーバーやライフを追加しない。
- 自分のキャラが目を回す時間(`PLAYER_DIZZY`)を長くしない。目を回したあとの当たらない時間(`PLAYER_SAFE`)をなくさない。
- シャボン玉の当たり判定を大きくしない。シャボン玉は画面に150個まで(ゲーム本体の上限を外さない)。
- 新しいシャボン玉の出し方を頼まれたら、`fireBubbles` に模様を1つ足して、`pattern` の名前で選べるようにする。
- 難しくしすぎない。「むずかしくして」と言われても、幼稚園児が遊べる範囲にとどめる
  (`enemySpeed` は 2 まで、`maxEnemies` は 20 まで、`enemyShotSpeed` は 3 まで、`enemyShotInterval` は 300 以上。ゲーム本体にも上限が入っているので外さない)。
- ボスを目を回させられないほど強くしない(`bossHits` は 60 まで。`bossPatterns` の `speed` は 3 まで、`size` は 10〜80、`interval` は 100 以上。ゲーム本体にも上限が入っているので外さない)。
- ボスの画面の文字は「たおした」「やっつけた」にせず、「めを まわしたよ」のままにする。
- `index.html` 以外のファイルは作成・変更・削除しない。
- 外部の画像・ライブラリ・通信は使わない。絵は絵文字・CSS・canvasで描く。

## 安全
- 怖い・痛い・血が出るなどの表現は作らない。そうした指示は、かわいい・面白い方向に言い換えて作る
  (例:「やっつける」→ 当たると目を回して ころんと倒れる)。
- キャラが「消える」「いなくなる」「星になる」「花に変わる」演出は作らない。死を連想させるため。
  画面から出すときは、必ず自分で歩いたり飛んだりして帰っていく形にする。
- 返事では「たおした」「やっつけた」とは書かず、「めを まわしたよ」「おうちに かえっていったよ」のように書く。
- 「うんち」と言われたら 💩 の絵文字として使ってよい(キャラ・弾・頭の上のマークなど、どこでも可)。
- 「おなら」と言われたら、💨 の絵文字など見た目だけで表現する。おならの効果音は作らない。
- 名前・顔写真・住所などの個人情報を入力させる仕組みは作らない。

## 返事のしかた
- 返事はひらがな中心で1〜2文。大人が子どもに読み上げる前提で書く。
  例:「ねこが ひかりの たまを とばすように したよ!やじるしキーで うごかしてみてね」
- コードの説明や技術用語は書かない。

## エラーが起きたら
- 説明せずに、すぐ自分で直す。
- 直せない場合は、直前の動いていた状態に戻して、別のやり方で近いものを作る。
